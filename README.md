# 双研 · 176对疑重确认工作台

沿用30条校准网站的界面及GitHub Pages公开托管。原Sites域名在本机普通网络被Cloudflare拦截，本任务直接使用已验证的GitHub Pages方式，不再创建额外Sites身份。

固定材料为2026-11-18 B3确认级176对：145对同DOI、31对题名几乎相同且同年同刊；涉及298条、140组关系，12组含3条以上，40对触及555批次。

本地原176表及原358复核表的对应人工四列经核对为空。初始网页无人工票。只提取公开书目信息，不上传Zotero笔记、附件、标签、关系或AI筛选建议。

主筛者逐对比较原A/B方向，提交合并保留A/B、确认不同保留双条或不确定保留双条。勾选实际核对依据；确认不同或不确定须有说明。草稿不计提交，待定不计已明确。

关系检查根据人工重复决定连接条目，检查多根、循环、不同/待定/未提交与传递关系的冲突。组级最终保留键另存且绑定当时原票版本，原票变化则需重核。唯一拟移除数按关系通过的条目计算，绝不把176对直接作为移除176条。实际合并与分母冻结另行核验。

CSV保留原358表的pair_id和A/B方向，含原人工四列及扩展信息。JSON保留原票、草稿、组级决定和修订历史；恢复前备份。合并草案只含通过组内关系检查的映射，并注明全批未决数量及未执行状态。

全部界面与数据内嵌单文件，无运行依赖。各设备/网址/在线与离线的存储独立，JSON转移进度。公开站不收集或同步个人判断。

书目快照为2026-10-08原生去重后数据；分层与原存续检查为2026-11-18。制作时本机Zotero实时API未运行，网页明确提示快照与执行前复核要求。

Node 22+，无需依赖：`npm run prepare-data`只读原资料、产生data；`npm run build`生成dist；`npm test`运行有针对性的校验。公开GitHub发布仅含dist的HTML、.nojekyll及本说明；不发布本机浏览器票和测试文件。
